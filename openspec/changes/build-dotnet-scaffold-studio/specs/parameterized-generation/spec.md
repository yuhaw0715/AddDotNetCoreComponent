## Purpose

將複雜的 CLI 引數轉換為具型別、可驗證且可預覽的操作流程，使使用者能安全產生專案、元件、設定檔與資料層成品。

## ADDED Requirements

### Requirement: 參數表單
系統 SHALL 將每個支援功能的常用參數直接顯示，並將其餘官方參數置於「進階選項」。布林值、列舉、路徑、清單、機密與一般文字 MUST 使用適合其型別的控制項。

#### Scenario: 開啟有進階選項的功能
- **WHEN** 使用者選擇具有大量官方參數的產生器
- **THEN** 系統先顯示必要及常用欄位，並允許展開完整進階選項而不遺失已輸入值

### Requirement: 輸入驗證
系統 MUST 在允許執行前驗證必填欄位、名稱格式、路徑邊界、參數相依與互斥關係，並以繁體中文將錯誤定位至對應欄位。

#### Scenario: Controller 名稱無效
- **WHEN** 使用者輸入不符合產生器限制的 Controller 名稱
- **THEN** 系統停用執行動作並在名稱欄位旁顯示可修正的驗證訊息

#### Scenario: 互斥選項同時啟用
- **WHEN** 使用者選取兩個官方規定不可並用的選項
- **THEN** 系統指出衝突、拒絕執行，且不自行靜默移除使用者選項

### Requirement: 命令預覽
系統 SHALL 在執行前持續產生唯讀的完整命令預覽，包含執行檔、個別引數、工作目錄及目標專案，但 MUST 遮蔽被標記為機密的值。

#### Scenario: 參數變更
- **WHEN** 使用者修改任一有效參數
- **THEN** 系統立即更新命令預覽，且預覽與實際傳入程序的引數語意一致

#### Scenario: 命令含有連線字串
- **WHEN** EF Core 功能需要使用連線字串
- **THEN** 系統優先引導使用具名連線字串，並在畫面、歷程與記錄中遮蔽直接輸入的機密內容

### Requirement: 檔案衝突處理
系統 SHALL 在可判定時預先列出預期輸出位置；若可能覆寫既有檔案，系統 MUST 要求額外確認且不得預設選取覆寫。

#### Scenario: 目標 Controller 已存在
- **WHEN** 預期輸出路徑已有同名檔案
- **THEN** 系統顯示衝突檔案、停用一般執行，並只在使用者明確選擇覆寫後進入高風險確認流程

### Requirement: 結果摘要
系統 SHALL 在命令結束後顯示成功、失敗或取消狀態、結束碼、耗時及已建立/修改/刪除的檔案；失敗時 MUST 保留可診斷輸出而不宣告部分產物已回復。

#### Scenario: 成功建立元件
- **WHEN** CLI 以結束碼 0 完成並建立檔案
- **THEN** 系統顯示成功摘要與檔案清單，並提供在 Finder 中顯示輸出位置的動作

#### Scenario: CLI 部分修改後失敗
- **WHEN** CLI 以非零結束碼完成且工作區已有檔案變更
- **THEN** 系統同時顯示失敗與實際檔案差異，且不得自動刪除或還原這些檔案
